# 数据与算法约定

## 输入和分组

每条 observation 来自上游已分 bin 的 piece，不是 GPS 定位日志。读取 cell_id、sample_id、dt、T_diff、ratio_pct、valid、bin_pos。固定 50 个 bin；同一 bin 的 piece 时间和 ratio 求和，所有 piece 的时间都有效时，该 bin 才可监督。无效时间在读取时置零，不做插值、不除以 ratio。存储张量仍为 `[B,M,50,3]`，最后一列是零占位，模型只读取明确约定的列。

分组先按 sample_id 排序，以 data_seed、日期、分区和 cell_id 确定固定成员；每组最多 M=64，尾组少于 3 条才丢弃。成员不随 epoch 变化，训练遮挡随 epoch 变化，验证遮挡固定 epoch=1000000。数据源必须具有互不重叠的日期/分区。

## V6 模型

Encoder 仅使用可见真实轨迹的 T_clean，50 维 MLP 输入，加进入时间编码，经过组内 Transformer。Decoder 使用可见轨迹状态、隐藏 mask token、隐藏轨迹 ratio 和进入时间，输出 softplus 秒数。隐藏标签和隐藏 bin_valid 不进入模型；真实轨迹结构由 traj_valid 决定。分桶时间编码的 600 秒端点属于第 19 桶。

## 损失与评估

训练 loss 是有可见有效值的组中，隐藏且有效 bin 的微平均绝对误差。轨迹总耗时 MAE/RMSE 先对该轨迹有效监督 bin 的误差求和，再取绝对值/平方；不能把单 bin MAE 乘以轨迹长度代替。

独立均值基线保留原实验定义：同 bin 的可见有效值取算术均值；该 bin 没有可见有效值时，采用组内可见有效 bin 均值。这是既定基线算法，保留它才能保持历史比较口径；它不是异常处理或数据读取失败后的静默回退。没有可见监督的组仍计入不可评分统计。零分母的指标明确记为 null，不伪造为零。
