Trajectory Representation v2

1. 目标

学习 (sub-link, time window) 的动态道路表征：

[
\boxed{r_{l,t}=h_{\mathrm{CLS}}}
]

其中 h_CLS 来自多轨迹 Transformer 的 CLS Token，用于 ETA / RP 等下游任务。

核心链路：

10m spatial profile
→ trajectory token
→ masked multi-trajectory modeling
→ CLS
→ dynamic link representation
→ downstream task

2. 数据层级

Original Link
→ 约 200m sub-link
→ (sub-link, time window)
→ K 条 trajectories
→ 每条 trajectory 按 10m 切 spatial bins

定义：

10m bin：描述单条 trajectory 的局部运动；

trajectory：一辆车经过 sub-link 的一次观测；

(sub-link, time window)：一个动态交通状态 sample；

trajectory token：单条 trajectory 的编码结果；

CLS：多条 trajectory 联合形成的 link-level dynamic representation。

3. 模型结构

Level 1：Trajectory Encoder

[v_i / v_norm, valid_i]
→ Input MLP
→ Position Embedding
→ Transformer Encoder
→ valid-bin Mean Pooling
→ r_k ∈ R^128

每条 trajectory 得到一个 token：

[
r_1,r_2,\dots,r_K
]

Level 2：Trajectory-level Transformer

输入：

[
[CLS,r_1,r_2,\dots,r_K]
]

输出：

[
[h_{\mathrm{CLS}},h_1,\dots,h_K]
]

最终定义：

[
\boxed{r_{l,t}=h_{\mathrm{CLS}}}
]

因此当前的 scatter_mean 不再作为 ours 的最终聚合方式，只保留为 baseline。

4. Masked Pretraining

Mask 单位是整条 trajectory，不是 10m bin。

r1  r2  r3  r4  r5
│   ×   │   │   ×
└──── visible ────┘
        ↓
[CLS] + visible trajectory tokens
        ↓
Trajectory-level Transformer
        ↓
CLS + visible hidden states
        ↓
Lightweight Decoder
        ↓
reconstruct masked trajectories

训练目标：

[
\text{visible trajectories}
\rightarrow
h_{\mathrm{CLS}}
\rightarrow
\text{masked trajectories}
]

目的是让 CLS 学习多辆车共享的 latent traffic state。

5. Downstream

[

]

Baseline 2：Speed-MLP

[
x=[L_n,\mathrm{MLP}(v_n)]
]

Ours

[
\boxed{x=[L_n,v_n,r_{l,t}]}
]

[

]

额外建议测试：

[
x=[L_n,r_{l,t}]
]

用于验证 CLS 是否只是在重新编码 mean speed。

最终定义

200m sub-link
→ 10m spatial bins
→ Trajectory Encoder
→ trajectory tokens
→ mask whole trajectories
